# Changelog

## v0.1.0 - 2026-11-14

- Upgrade MyGo runtime and tools to v0.9.0.
- Align separators, table headers, card/listbox dividers, resize and navigation indicators, chart grids, tree guides, connectors and PIN carets to device pixels at fractional DPI and UI zoom. Layout remains in DIPs. Decorative dividers use one device pixel; sized strokes retain their rounded DIP widths.
- Table exposes SeparatorSlot for its header divider. Separator stroke colors use Indicator.Background for all line types; a final Style Background or Material replaces the default stroke.
- Adapt components to MyGo v0.9.0's live regions. Chart's description line is no longer a status, so a keyboard selection is announced once and pointer hover is not read aloud. CommandPalette's searching and error messages keep stable identities and are announced once when they appear; MyGo reads their later text changes, and clearing them reads nothing. FileUpload keeps empty reading/error status regions mounted, so adding or changing a message while exposed is read once. Hidden updates are silent, and mounting or exposing an existing message does not announce it as a change. The empty and loading statuses of Listbox, Select, SelectMenu, InputMenu, Tree, Chart, DropdownMenu and ContextMenu filtering keep stable identities: they are not read when they first appear, and a change of their text while shown is read once.
- Main, HeaderLayout and FooterLayout are the main, banner and content-information landmarks. Tabs content is a tab panel named after its tab, and each tab points at its built panel with Controls.
- Calendar's day, month and year grids are grids instead of tables, as Reka UI's calendar grid, so with ReadOnly the grids and their cells report read-only. InputRating and the InputDate and InputTime segments report read-only to assistive technology.
- Table's OnChange also fires once per finished column move, resize or double-click fit, reported by MyGo's table. The internal active row that OnActivate reads follows its record across sorting and consecutive SetRows calls before a build; when SetRows removes that record, no row is active and Enter does nothing.
- Re-verified the selected-text IME cancellation known issue under MyGo v0.9.0: it remains, and a headless probe test now tracks it. Documented that a window out of sight, which since v0.9.0 includes a minimized window on Windows and on Linux under X11, draws no frames, so toasts that expire meanwhile close as it shows again.

### Migration notes

- **Component import path.** The `nui` package moved to `github.com/josexy/nuxt-ui-go/ui`. Update existing imports and run `go mod tidy`.
- **Landmarks.** Main, HeaderLayout and FooterLayout now expose `ui.RoleMain`, `ui.RoleBanner` and `ui.RoleContentInfo`, and a window should have at most one of each. An app that builds a nested or extra instance, such as a Header inside a card or a preview, opts it out in the same build with `.Role(ui.RoleGroup)` on the returned element; layout, styles, focus and children stay the same.
- **Tab panel names.** Tabs panels are now named after their tab's Label instead of "{name} content" (`contentNamed`). Tests or automation that find a panel by its old name should find it by its tab's label, or by the `ui.RoleTabPanel` role, since the tab now has the same name. An app that overrides `nuxtui.contentNamed` in its catalog keeps its own panel name.
- **Table OnChange on column gestures.** `TableOptions.OnChange` now also fires after the user moves, resizes or fits a column. Apps that treat every OnChange as a data or selection change should use OnSortChange and OnSelectionChange for those, and can save `TableState.List.Columns` from OnChange.
- **BREAKING (behavioral): programmatic focus scrolls.** Since MyGo v0.9.0, focus moved by the keyboard or by a component scrolls the containers around the target as little as needed to show it: roving focus in Tabs and menus, Form's first invalid field, and focus returning when overlays close. A target that is already fully visible does not scroll. App code that must keep the scroll where it is passes `ui.FocusOptions{PreventScroll: true}` to `Element.Focus`; `Handle.Focus` takes no options in MyGo v0.9.0.

## v0.0.2 - 2026-11-07

Components that animate, wait, or are hidden no longer keep the window building the view.

### Migration notes

- Marquee moves its content in frames that only repaint and builds the view about once a second, instead of on every frame. MarqueeState.Offset is therefore the phase as of the last build; read it in a build. Content scrolled out of a ScrollArea, clipped away, or kept mounted in a hidden panel now stops the motion, as it does Carousel autoplay, so Active=false is only needed for content hidden by other means.

### Performance

- A Chart or horizontal Listbox inside a hidden KeepMounted panel no longer rebuilds the view continuously; it measures itself once it shows.
- A toast's progress bar empties in frames that only repaint, so a toast no longer rebuilds the view at the display's rate for its whole lifetime.
- FileUpload and CommandPalette no longer poll every 16–20 ms while a worker or the native file dialog is pending; the worker wakes the window when its result is ready.
- An open CommandPalette no longer regroups and copies its results on every frame, and a Table with OnSelectionChange no longer copies the whole selection on every frame.
- Skeleton's pulse repaints at 30 frames a second.

## v0.0.1 - 2026-11-07

Visual and interaction parity with Nuxt UI v4.12.0.

### Migration notes

- Sidebar adds Description and Actions, and now provides the actual parts and region spacing for both the desktop and overlay layouts. An empty header no longer takes up space, and when content being edited is removed because the width becomes zero or the layout crosses a breakpoint, focus returns to an available entry point. The vertical padding of the body and footer is now 16 DIP.
- HeaderLayout adds style entry points for the leading content and the title text container. Stable region identities preserve editors in Actions, and an empty title creates no heading node. The default gap inside the Header and Footer action areas is 6 DIP, and Footer's Actions options now apply to a separate container.
- FooterColumns supports Active, per-item OnSelect/PreventDefault, and per-item styles, and links use the native Link role. The column gap is now 32 DIP. The preferred minimum column width drives wrapping and is constrained by the available space, and columns are top-aligned. The Gallery, website, and bilingual examples are updated.
- Splitter's Disabled now locks only the divider; to disable the pane content, disable the parent container. The visible divider takes 1 DIP, and an 8 DIP drag area overlaps the pane edges, which fixes gaps where nested dividers meet. Adds Orientation, Label, KeyboardResizeBy, and divider style parts; fixes duplicate notifications at the bounds; supports Home and End; and reports the accessible range in the bound value's unit.
- Marquee adds Repeat and the Body style part. When unset, content is still repeated 4 times; an explicit 0 builds no content. Motion stops when a parent is disabled, and the offset is normalized to the content cycle. The Gallery, website options, and bilingual examples are updated for both changes.
- Carousel fixes unintended wrapping when dragging with Wrap=true, lost focus after removing the current slide, and the centering of fixed-size arrows. Adds previous/next button and icon options, WatchDrag, per-item styles, and parts. StopOnInteraction now defaults to true, so manual navigation pauses autoplay; set it to false explicitly to keep automatic resumption. Timer and drag notifications are now sent after the build, and Disabled and focus on a control pause autoplay. The Gallery and website are updated.
- Chart's default height is now 300 DIP, and when Legend is unset the legend appears only with more than one series or slice. Donuts default to a 24 DIP thickness, and an explicit DonutInnerRadius keeps precedence. Adds axis, data point, tooltip, center content, color, and selection notification options; fixes RTL coordinates and color cycling; and documents that charts are drawn with MyGo and where they differ from the TanStack Charts reference.
- FileUpload supports wildcards, comma-separated lists, and compound extensions. With Dropzone off, no drop target is registered, and a disabled parent container also discards late selection results. OnChange reports only actual queue changes, and OnReject is new. After a deletion or cancellation, focus returns to the selection entry point. Adds icon, preview accessory, and delete button options, Highlight, list position, and style parts, while keeping the native multi-file queue. The Gallery, website options, bilingual descriptions, and copyable programs are updated.
- Drawer no longer shows a close button by default. Passing Close options enables it implicitly, and CloseButton=true restores the old behavior. OnSnap fires only when the index actually changes, and drags blocked by Dismissible=false now fire OnClosePrevent. Adds Handle and Inset, a visible handle bar, and a single scrolling container. Fixes the footer being clipped at the lowest height, and Sidebar's drawer mode keeps a fixed footer and close entry. Close thresholds must be finite and non-negative, and 0 uses the default. The Gallery, website, and bilingual descriptions are updated.
- NavigationMenu now defaults to Primary / Soft (pill); use Color=Neutral to keep neutral text. Adds LinkVariant, an active indicator line, and per-item accessories and styles. Compact applies only to vertical menus, and horizontal arrow keys stop at the ends. Adds cancelable navigation, a public Expanded state, initial and sibling expansion controls, and notifications. Fixes focus restoration and RTL indentation. The Gallery, website, and bilingual descriptions are updated. Compact tooltips and popovers stay on by default, as in the native implementation.
- CommandPalette's default search now also matches descriptions and suffixes, and results from the same group are shown together. Old requests are now canceled correctly when the limit changes, the palette is closed and reopened, the user returns from a child level, or the palette is disabled. Adds delay, input, and icon options, command accessories, cancelable execution, and keeping the palette open. Fixes returning focus and the scope of the Root style. The default limit is still 200. After replacing a custom Search closure, call Refresh. The Gallery, website, and bilingual descriptions are updated.
- Tree's indeterminate state now follows Multiple, BubbleSelect, and PropagateSelect. When a selection callback replaces the model, the earlier click no longer expands the new node. Adds OnExpandedChange, node styles, and leading and trailing content builders. Fixes type-ahead search, the Neutral focus color, and name inheritance. Loaded empty branches no longer get a folder icon and arrow automatically; set Icon explicitly for a fixed look. The Gallery, website, and bilingual descriptions are updated.
- Clearing Table's sort restores the input order of the latest SetRows, which is also kept for rows that compare as equal. List.SortBy now actually performs multi-column sorting, and removing a column or turning off its sorting removes its sort entries. Call InvalidateSort when external conditions that a comparator depends on change; use ManualSorting when you sort the data yourself. Adds separate sort and selection notifications, row activation, caption and loading content, and per-column styles. The Gallery now uses this project's components, and the website and bilingual descriptions are updated.
- ColorPicker's default width changes from a fixed 280 DIP to MD's 168 DIP, and five sizes are added. OnChange calls are merged over 50 ms by default while the bound color still updates immediately; for a notification on every change, set `Throttle: nui.Set(time.Duration(0))`. Re-entering the same channel value no longer notifies, RGBA form drafts are tracked as one field, and editing an actual channel rebuilds the sRGB color. In RTL, the native color panel is fixed to LTR, which fixes slider input and drawing directions disagreeing; the RGBA fields still follow the page direction.
- Clearing both ends of InputDateRange now sends a single range notification, and OnRangeChange is new; Calendar.OnChange remains for compatibility. Range input now enforces all of Calendar's range limits. In 12-hour mode, InputTime now correctly crosses noon and midnight when the hour is incremented or decremented. Segmented date and time inputs add an avatar, a trailing loading indicator, Neutral highlighting, steps, and a reference value. Time inputs add bounds, an unavailable predicate, granularity, and optional step snapping.
- By default, selecting the same date again in Calendar now deselects it; set PreventDeselect=true to keep the old behavior. Home and End now go to the week boundaries, and the year navigation and heading view switch are shown by default. WeekStart still defaults to Sunday.
- With its search field hidden, SelectMenu still filters by the retained query; to show your app's results directly, set ExternalFilter or IgnoreFilter. The clear button always clears the query, and ResetModelValueOnClear controls only the selected value. Root, Leading, Label, and Trailing styles no longer apply to popup options; use the corresponding Item parts. The default search field no longer adds a search icon.
- The first increment or decrement of an empty InputNumber now uses the starting value, and StepSnapping and FocusOnChange now default to true; turn them off explicitly to restore free stepping or keep focus on the buttons. InputTags' Backspace now selects a tag before deleting it, and Style.root now refers to the whole field.
- Form's LoadingAuto defaults to true, so inner controls are disabled automatically after BeginAsync; to allow editing while waiting, set `nui.Set(false)`. A successful submit clears Dirty for the current fields, and Reset uses the current model from the next build as the new baseline.
- Breadcrumb now runs the last item's OnSelect; leave the callback empty if the item only shows the current location. Banner's container padding is now configured through Body. Stepper's step list is configured through List, and Root contains the list and the new body.
- DropdownMenu and ContextMenu arrow keys now stop at the first and last items by default; set MenuOptions.Loop=true to restore wrapping. UI.Trailing now applies to the row-end container, and the check icon can be configured separately through Indicator.
- ToastOptions.UI.Actions now configures the action container; put individual button styles in ButtonOptions.UI of each Actions item. If you use the old Action string and customize its button style, switch to a single-item Actions list.
- InputMenu's OpenOnClick now defaults to false, matching the upstream prop; to open on click, set `nui.Set(true)` explicitly. SearchSelect keeps its old open-on-click behavior.
- `StepperOptions.Linear` is now an `Optional[bool]` that defaults to true. Wrap existing bool values in `nui.Set(...)`; for non-linear navigation, set `nui.Set(false)` explicitly.
- `InputTimeOptions.TwelveHour` is now an `Optional[bool]` that defaults to the language and locale format. Wrap existing bool values in `nui.Set(...)`; for a fixed 24-hour clock, set `nui.Set(false)`.
- FileUpload's file size message now uses `fileSize`, and its `size` parameter is now a formatted string. Apps that overrode the old `fileSummary` key need to migrate.
- Pagination's English accessible names are now `First page`, `Previous page`, `Next page`, and `Last page`. Update tests or automation scripts that locate controls by name.
- With MyGo v0.8.3, `ui.Tester`'s `Click`, `ClickWith`, and `RightClick` fail when the named element does not take the press at its center. App tests that click by name a PinInput, a Splitter or Sidebar divider, a date range group, a FormField by its full name, or a control under a modal backdrop should click the control inside instead, such as the `… start day` segment or the visible field label, or use `ClickAt` on the element's bounds.

### Default behavior changes

- ScrollArea clips its content to Root's rounded corners, which fixes content covering the corners. The Gallery and website add orientation, scrollbar, and position controls.
- Select option icons align with the first line of the description, and multiple selection skips separators for empty labels. Fixes the Neutral focus color, explicit names, trigger focus after closing, and the behavior of Dismissible=false in single selection. Popover's internal theme container no longer covers the panel's background, border, and rounded corners.
- Container's default horizontal padding is 16, 24, or 32 DIP depending on the window width, with breakpoints at 640 and 1024 DIP. An explicit Padding keeps the old behavior.
- InputTags splits only on commas by default; to restore the old separators, set `Separators: ",;\n"`.
- The whole interactive UploadArea in FileUpload is focusable, and Enter or Space opens the picker. The Choose button appears only with UploadButton or `Interactive: nui.Set(false)`.
- Marquee fades at both ends by default, repeats its content 4 times, and scrolls even short content. By default, the content builder is called 4 times per build; adjust this with Repeat.
- InputRating's arrow keys stop at the first and last values, and with Clearable the keyboard can clear the rating. When CheckboxGroup reaches Max, unchecked items can still receive focus.
- CheckboxGroup is now a single Tab stop where arrow keys only move focus and do not wrap by default; RadioGroup wraps by default. In both group types, arrow keys follow the horizontal or vertical layout, and Loop can change the wrapping explicitly.
- User no longer generates an initials avatar when no avatar is configured. Carousel's page counter is now an accessible value and is no longer shown on screen.
- Empty-state messages are unified as `noData` and `noMatch`, and apps that override the old message keys keep working.
- With MyGo v0.8.3, Link, actionable Breadcrumb items, and FooterColumns items activate with Enter only; as on the web, Space is left to the container around them. Use Button where Space should activate too.
- With MyGo v0.8.3, Toast timers keep running while the window is in the background or hidden, and focus inside a toast pauses them only while the window has focus. A toast that expires in the background closes before the window shows again.
