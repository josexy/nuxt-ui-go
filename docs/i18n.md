# 中英文与全局语言切换

NuxtUI Go 使用固定 MyGo 依赖提供的 `i18n.NewLibraryCatalog`，内置英文 `en` 和简体中文 `zh-Hans`。目录位于 `locales/`，命名空间为 `nuxtui`。组件从当前窗口的 `c.Locale()` 读取语言，不维护第二份全局语言状态，也不修改应用的语言列表。

## 应用接入

没有应用语言目录的程序，在创建窗口前调用：

```go
mygo.App.SetLanguages(nui.SupportedLocales()...)
```

`SupportedLocales()` 返回独立切片 `[]string{"en", "zh-Hans"}`。已有应用语言目录的程序继续使用 MyGo `i18n.Register` 注册自己的目录，由应用声明支持的语言，不必另外声明组件语言。不要对组件库目录调用 `i18n.Register`。

在 UI 动作中调用 `mygo.App.SetLocale("zh-Hans")` 或 `mygo.App.SetLocale("en")`，MyGo 会刷新全部窗口、更新原生控件并保存偏好；`SetLocale("")` 恢复跟随系统。启动时无需强行设置默认语言，MyGo 会根据应用支持的语言、保存的选择和系统语言解析当前语言。`MYGO_LOCALE=en` 可用于自动化测试，避免保存测试中的语言选择。

Gallery 顶部的 English / 简体中文 按钮演示全局切换。各窗口仍持有独立的输入、选择、表单和主题状态。

## 文案范围与覆盖

- 组件内置操作及可访问名称：清空、关闭、移除、取消、重试、上一页/下一页、日历切月、数值增减、侧栏和轮播操作等。
- 默认提示与状态：搜索、创建选项、加载、空列表/表格/图表、命令面板、PIN 长度、上传状态与文件规则错误。
- 内置表单错误：通用无效值、数字、日期和时间解析错误。已保存的内置错误在语言变化后重新格式化；语言变化不作为一次表单编辑。
- Calendar 的月份、年份和星期使用 MyGo 的日期格式化能力。MyGo 自带控件的简体中文目录随库一同引入，例如 ColorPicker 的饱和度与十六进制名称、编辑器的系统菜单文案。

Label、Description、Placeholder、ErrorMessage、EmptyText、ChooseLabel、CloseLabel 等显式选项，以及业务校验、服务端错误、Toast 标题、菜单项目、表格数据，作为应用文案处理，保留现有选项优先级，不自动翻译。上传规则产生的内置错误保留翻译身份；调用方覆盖 `UploadFile.Error` 后，该字段作为业务文字保留。组件不会翻译或重置输入草稿、选区和业务值。

PinInput 默认文本模式使用 `pinCharacters`，数字模式使用 `pinDigits`。没有显式 Label 或 FormField 标签时，真实编辑器的默认可访问名称为 `5 characters` / `5 个字符`，Numeric 模式为 `5 digits` / `5 位数字`；数量随 Length 变化，英文支持单复数。应用可覆盖 `nuxtui.pinCharacters` / `nuxtui.pinDigits`。这不是可视槽位的 Placeholder；显式 Label、字段标签和 Placeholder 保持调用方提供的文字，切换语言保留焦点、选区、内容及事件计数。

其他组件使用对应语言键：SelectMenu/InputMenu 创建行为使用 `createItem`，AvatarGroup 溢出可访问名称使用 `morePeople`，日历范围、关闭/清空/文件操作也沿用已有目录。参数枚举、图标、分隔符和 en/zh-Hans 下相同的百分比符号不单独建立翻译键；Timeline 的标题/日期等仍属于应用文案。

需要统一调整内置文案时，在应用自己的 MyGo 目录中加入带命名空间的键。例如应用的 `en.json`：

```json
{
  "@@locale": "en",
  "nuxtui.noMatch": "Nothing matched",
  "nuxtui.clearNamed": "Clear {name}"
}
```

对应 `zh-Hans.json`：

```json
{
  "@@locale": "zh-Hans",
  "nuxtui.noMatch": "没有匹配的内容",
  "nuxtui.clearNamed": "清空{name}"
}
```

空状态文案与 Nuxt 一致：列表本身为空时用 `noData`（No data / 没有数据），有查询词但无匹配时用 `noMatch`（No matching data / 没有匹配的数据）。旧键 `noOptions`、`noResultsFound`、`noResults`、`noRecords`、`noItems` 仍在目录中；应用若已覆盖其中某个键，对应组件继续使用应用的覆盖文案。

应用目录正常通过 `i18n.NewCatalog` 和 `i18n.Register` 接入。未覆盖的键继续使用库内翻译；库内不支持的语言回退到英文。全部键见 [英文目录](../locales/en.json) 和 [简体中文目录](../locales/zh-Hans.json)。带参数的文案必须保留参数名与类型；数量文案使用 MyGo 支持的 ICU plural，不通过拼接英文后缀构造。

## 格式与语言范围

国际化覆盖组件文案和日历展示。日期输入仍为公历 `YYYY-MM-DD`，时间输入遵循既有 `HH:MM`、秒数及 `AM/PM` 选项，数字编辑仍使用小数点。语言切换不会重新解析现有值；`WeekStart` 仍由应用配置，不按语言自动改变。完整地区输入格式、多历法、繁体中文尚未内置，RTL 使用体验尚未全面验证。

平台支持和已知输入限制见 [兼容性说明](compatibility.md)。
